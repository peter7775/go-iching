# Dataset note

Tato verze projektu už používá plný embedded dataset vytvořený z přiloženého souboru `iching_wilhelm_translation.js`, který obsahuje export objektu pro všech 64 hexagramů včetně `wilhelm_judgment`, `wilhelm_image` a `wilhelm_lines`. README repozitáře `adamblvck/iching-wilhelm-dataset` uvádí, že JSON obsahuje 64 objektů a je určený pro použití ve webech, serverech a aplikacích. [web:5][file:131]
